# 🏥 Careplus Specialized Hospital
A modern, responsive, and lightweight Hospital & Clinic Management Dashboard featuring a Glassmorphism UI design and a Node.js/Express.js backend.

---

## 🌟 Features

* **Glassmorphism UI:** Semi-transparent frosted glass design optimized for background images.
* **Fully Responsive:** Adapts seamlessly to mobile, tablet, and desktop screens with a slide-out sidebar for mobile viewports.
* **Dashboard Analytics:** Overview cards for patient count, daily appointments, available cabins, and active doctors.
* **Cabin & Doctor Management:** View status badges for available/occupied cabins and doctor profiles.
* **REST API Integration:** Express.js endpoints for handling authentication, dashboard statistics, doctor listings, and room statuses.
